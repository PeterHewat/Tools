About

  • JSON is part of a set of Tools that run entirely in your browser and keep working offline.
  • Nothing you open or paste leaves this page: the draft is kept only for this tab, so a reload keeps it and closing the tab ends it. The Exact values you turned on are kept with it.
  • A new tab opens on a small sample to try things on; Clear empties it, and it does not come back in that tab.
  • Light / dark — the sun or moon beside Help switches the theme of every tool; on a phone it is at the top of this panel.

Views

  • Text — edit the JSON, with colours, line numbers and live checking.
  • Tree — fold objects and arrays. The gutter shows the line each value starts on in the text (the column, when the text is one line). Double-click (double-tap) a row, or press Enter, to show it in the text. Expand all and Collapse all are at its top right.
  • YAML, CSV, Types, Schema — the document converted, following your edits. Export and Copy take whatever view is shown.
  • Exact values, above Types and Schema, lists the places that hold only a few different strings. Turn one on and it is typed as those strings ("json" | "svg", an enum in the schema) rather than any string.
  • CSV makes every array a table — a row per item, a column per key — one after another under their names. The gutter gives each row's line in the JSON. With several tables, Copy and Export take the one the cursor is in. An array inside a table is a cell of it, written as JSON.
  • CSV in — import a .csv or .tsv file and it opens as JSON, one object per row; paste CSV and Convert CSV to JSON offers the same. Numbers, true, false and null become values; everything else stays text.

Editing

  • Find (the magnifying glass, or Ctrl + F) searches the view shown: the text, the converted views, or the keys and values of the tree. Its button closes it again.
  • Format and Minify, over the text's top right, keep numbers and strings exactly as written, so large IDs are never rounded. The one that matches how the text is laid out stays lit until an edit changes that.
  • Fix appears when the text is almost JSON — comments, trailing commas, single quotes, unquoted keys, NaN, Python's True / None — and corrects just those places.
  • Settings (the cog) — indent and key sorting for Format, syntax colours in every view, the style of the path in the status bar, and turning a string that holds JSON into real JSON, or back.
  • A long document is edited a page of 5,000 lines at a time; everything else works on the whole of it.
  • Status — on a phone the status bar folds away behind the round button at the bottom right, green while the text is valid and red when it is not. Tap it to open the status, the error and Fix over the editor, and again to fold them away.
