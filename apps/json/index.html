About

  • JSON is part of Tools, a set of tools that run entirely in your browser and keep working offline.
  • Nothing you open or paste leaves this page: the draft is kept only for this tab, so a reload keeps it and closing the tab ends it.

Views

  • Text — edit the JSON, with colours, line numbers and live checking.
  • Tree — fold objects and arrays. The gutter shows the line each value starts on in the text (the column, when the text is one line). Double-click a row, or press Enter, to show it in the text.
  • YAML, CSV, Types, Schema — the document converted, following your edits. Copy and Download take whatever view is shown. CSV uses the array around the cursor (or selected in the tree), else the document's first array.

Editing

  • Format and Minify keep numbers and strings exactly as written, so large IDs are never rounded.
  • Fix appears when the text is almost JSON — comments, trailing commas, single quotes, unquoted keys, NaN, Python's True / None — and corrects just those places.
  • Settings (the cog) — indent and key sorting for Format, syntax colours in every view, the style of the path in the status bar, and turning a string that holds JSON into real JSON, or back.
  • A long document is edited a page of 5,000 lines at a time; everything else works on the whole of it.
