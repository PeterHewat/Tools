Help

  • The draft is kept only for this tab, up to 2 MB. Reloading restores it; a new tab starts on an example. Light / dark applies to every tool.

Input

  • Text is hashed as its exact UTF-8 bytes. Invisible characters are drawn, so what you see is what is hashed: a tab as a line across its width, a carriage return as ␍, others by their code point. The byte count shows beside Input.
  • Choose or drop a file to hash its bytes; it never leaves your browser. Files are limited to 64 MiB because Web Crypto reads them whole. A file must be chosen again after a reload.
  • The trash button empties the text and the file.

Digests

  • SHA-256, SHA-384, SHA-512 and SHA-1 are computed together, in hex or Base64. SHA-1 is legacy: do not rely on it for security.
  • Paste an expected digest under Compare, hex in either case or Base64, spaces ignored: it names the algorithm it matches and marks that line.
  • With HMAC on, each line is the HMAC of the input with that hash, keyed by a non-empty key in UTF-8, hex, Base64 or Base64url. The key is kept in this tab's draft.
  • A digest is not encryption. Web Crypto needs HTTPS or localhost.
