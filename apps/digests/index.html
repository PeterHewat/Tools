Text and files

        

          Text is hashed as its exact UTF-8 bytes, including spaces and newlines. Pick or drop a
          file to hash its binary bytes locally. Files are limited to 64 MiB because Web Crypto
          reads them into memory.
        

        
Algorithms

        

          SHA-256, SHA-384 and SHA-512 are available. SHA-1 is legacy and should not be used for
          security. Outputs are hex and Base64.
        

        
HMAC

        

          Enable HMAC and enter a non-empty key in UTF-8, hex, Base64 or Base64url. Keys and content
          are never stored. A hash is not encryption.
        

        
Web Crypto requires HTTPS or localhost.
