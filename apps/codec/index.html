Convert either way

        

          Pick the format for each pane and edit either side. The other pane follows immediately.
          Load example offers Unicode, URL, binary and invisible-character samples. Conversions
          preserve bytes; text uses UTF-8 and invalid UTF-8 is rejected.
        

        
Formats

        

          Base64 accepts whitespace and optional padding; Base64url uses an unpadded URL-safe
          alphabet. Both reject nonzero padding bits. Hex accepts whitespace between complete byte
          pairs. URL uses percent encoding for a component (encodeURIComponent); + is a literal
          plus, not a space.
        

        
Inspect

        

          The byte view includes invisible characters, including newlines and a UTF-8 BOM. Input
          stays only in memory.
