Help

  • The draft is kept only for this tab, up to 2 MB. Reloading restores it; a new tab starts fresh. Light / dark applies to every tool.

Editing

  • Every field holds the same bytes. Edit any of them and the others are rewritten as you type; the one you edit is left as you wrote it.
  • While what you type cannot be read yet (an odd hex digit, a cut Base64 group), the error shows beside its name and the other fields keep their last value, dimmed.
  • Bytes that are not valid UTF-8 have no text: the UTF-8 field stays empty and says so. Typing in it starts again from text.
  • A new tab opens with several scripts, composed and combining accents, emoji, URL punctuation, a byte order mark, Windows line breaks, nonbreaking and zero-width spaces, a tab and a null. The byte count appears beside Hex. Select all and delete in any field to empty every format.

Formats

  • UTF-8 text is kept byte for byte: a Windows line break stays \r\n, and invisible characters are drawn: a tab as a line across its width, control characters as symbols (␀ ␍), others by their code point, such as U+FEFF for a byte order mark. Hover a symbol for its name.
  • URL component is percent encoding as encodeURIComponent writes it; a byte that is not part of UTF-8 text is written as %XX too. A + is a plus, not a space.
  • Base64 accepts white space and optional padding; Base64url uses the unpadded URL-safe alphabet. Both refuse padding bits that are not zero.
  • Hex accepts white space between complete byte pairs, in either case.
  • Digests, beside UTF-8 text, opens the Digests app on the same text, to see its SHA digests or HMAC.
