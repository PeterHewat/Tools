    Help
    
      
    
      
    
        
    
        
      
          
    • 
            Codes are made here, in your browser: what they hold is never sent anywhere. They are
            static, so they keep working without this site, but what they hold cannot change once
            printed.
          
      • 
          
    • 
            The draft is kept only for this tab, up to 2 MB. Reloading restores it; a new tab starts
            fresh. Light / dark applies to every tool.
          
      • 
        
    
        
    What a code holds
    
        
      
          
    • 
            Link opens a website; one typed without https:// gets it. Email,
            Call and SMS start a message or a call, written and ready to send.
            WhatsApp opens a chat through wa.me.
          
      • 
          
    • 
            Wi-Fi joins a network. The password is readable by anyone who scans the code.
          
      • 
          
    • 
            Contact is a vCard the phone offers to save. Event is a calendar entry,
            its times in your time zone.
          
      • 
          
    • 
            Barcode: Code 128 for printable ASCII, up to 80 characters; EAN-13 and UPC-A for
            product numbers. Enter one digit less to have the check digit calculated, or all of them
            to have it checked.
          
      • 
        
    
        
    Design
    
        
      
          
    • 
            Colours, shapes, a logo and a frame change how a QR code looks, not what it holds. A
            barcode takes the colours only.
          
      • 
          
    • 
            Scanners need contrast: a dark code on a light background reads best. A warning under
            the preview says when the colours may not scan.
          
      • 
          
    • 
            A logo covers the middle of the code, so error correction goes up to H, which recovers
            up to 30% of it. Keep the logo small and test the printed code.
          
      • 
        
    
        
    Download
    
        
      
          
    • 
            Size picks the image's width, from XS (about 256 pixels) to XL (about 4096); its height
            follows. Each module is a whole number of pixels, so the PNG has no blurred edges, and
            the SVG uses whole numbers only. SVG scales to any size for print.
          
      • 
          
    • 
            Every code keeps the clear border scanners need: four modules around a QR code, and the
            standard space before and after a barcode's bars.
