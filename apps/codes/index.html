Help

        
      

      

        
Make a QR code

        

          Use text, a URL, or the Wi-Fi preset. QR codes are encoded locally as UTF-8, with an
          explicit UTF-8 ECI marker, using an encoder maintained in this repository.
        

        
Scanning

        

          Higher error correction adds redundancy and can make a larger code. Keep a quiet zone of
          at least four modules, high contrast, and enough physical size for the amount of data.
          Always test your exported code with the intended scanner.
        

        
Export

        

          SVG is a clean vector image with a white background. PNG uses an integer number of pixels
          per module. Neither export includes the tool interface. Wi-Fi passwords are visible to
          anyone who scans the code; inputs remain only in memory.
