Code types

        
    
          
  • 
            QR encodes Unicode text, a URL, or Wi-Fi. Code 128 encodes printable ASCII (up to 80
            characters), with compact pairs for even-length all-digit input.
          
    • 
          
  • 
            EAN-13 and UPC-A encode product identifiers. Enter 12/11 digits to calculate the check
            digit, or 13/12 digits to validate it. These are encoders, not a source of assigned
            product identifiers.
          
    • 
        

        
Export and scanning

        
    
          
  • 
            Export width sets the actual SVG/PNG dimensions. QR exports are square; barcode height
            follows its width. SVG is a scalable vector image. PNG uses integer module widths and
            centers spare pixels in the quiet zone.
          
    • 
          
  • 
            Every code is exported with the clear border scanners need: four modules around a QR
            code, and the standard space before and after a barcode's bars. Keep the output high
            contrast and test with the intended scanner.
          
    • 
          
  • 
            The preview stays in place while editing. It dims and export buttons disable when the
            current content is invalid or being updated.
